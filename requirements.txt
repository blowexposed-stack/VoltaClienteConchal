# 💬 VoltaCliente Conchal — Micro-SaaS de Retenção via WhatsApp

flask>=3.1.3
gunicorn>=26.0.0
requests>=2.34.2

## 🚀 Rodar localmente

```bash
pip install -r requirements.txt
python app.py
# Acesse: http://localhost:5000
# Demo: admin@demo.com / demo123
```

## 📁 Estrutura

```
├── app.py                      # Backend Flask — todas as rotas
├── disparador.py               # Cron job de envio diário
├── notificacoes.py             # SMTP para notificar o admin
├── requirements.txt
├── Procfile                    # Render/Heroku
├── runtime.txt
├── database/
│   ├── models.py               # SQLite — todas as tabelas
│   └── retencao.db             # Criado automaticamente
├── templates/
│   ├── login.html
│   ├── dashboard.html          # Painel com 4 abas
│   ├── agenda_publica.html     # Página pública /agendar/<slug>
│   ├── pagamento.html
│   └── 404.html
└── static/
    ├── manifest.json
    └── service-worker.js
```

## ⚙️ Variáveis de ambiente (Render)

| Variável            | Descrição                                      |
|---------------------|------------------------------------------------|
| `SECRET_KEY`        | Chave Flask (string aleatória longa)           |
| `BASE_URL`          | URL pública do app (ex: https://app.onrender.com) |
| `EVOLUTION_URL`     | URL da Evolution API                           |
| `EVOLUTION_APIKEY`  | Chave da Evolution API                         |
| `EVOLUTION_INST`    | Nome da instância Evolution                    |
| `ANTHROPIC_API_KEY` | Chave da API Anthropic (IA WhatsApp)           |
| `MP_ACCESS_TOKEN`   | Token Mercado Pago                             |
| `MP_CHECKOUT_URL`   | URL do checkout MP                             |
| `SMTP_HOST`         | Servidor SMTP (ex: smtp.gmail.com)             |
| `SMTP_USER`         | Usuário SMTP                                   |
| `SMTP_PASSWORD`     | Senha SMTP                                     |
| `ADMIN_NOTIFY_EMAIL`| E-mail para receber alertas de login           |

## 📱 Configurar webhook Evolution API

1. No painel do dashboard, clique em "⚙️ Configurar Evolution API"
2. Copie a URL do webhook exibida
3. Cole nas configurações da sua instância Evolution
4. Evento necessário: `messages.upsert`

## 🤖 Como funciona a IA + Handoff

- Cliente manda mensagem no WhatsApp → IA responde com link de agendamento
- Dono digita qualquer coisa → IA pausa por 12h automaticamente
- Após 12h sem interação do dono → IA retoma automaticamente

## 💳 Mercado Pago

Configure o webhook de pagamentos em:
`https://seuapp.com/webhook_pagamento`

Eventos: `payment.created` e `payment.updated`
